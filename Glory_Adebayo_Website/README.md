# Glory David Adebayo — academic website

Static website prepared for https://glorydavidadebayo.github.io.

## Preview
Open index.html in your web browser. No installation is needed.

## Publish for free on GitHub Pages
1. Create a public repository called `glorydavidadebayo.github.io` in the `glorydavidadebayo` account. Initialize it with a README if needed.
2. Extract this ZIP. In the repository, choose **Add file → Upload files**. Upload the extracted files directly into the repository root, not inside a website folder. The root should contain index.html, styles.css, portrait.jpeg, and cv.pdf. Include .nojekyll if your file chooser shows it. It is optional for this simple site.
3. Commit the upload to the main branch.
4. Open **Settings → Pages**. Under Source, select **Deploy from a branch**. Select **main** and **/ (root)**, then Save.
5. Wait for deployment. GitHub says publication can take up to 10 minutes. Visit https://glorydavidadebayo.github.io.

Official instructions: https://docs.github.com/en/pages/quickstart

## Update later
- CV: replace `cv.pdf` with the newest PDF under the same filename, then commit. The existing CV links keep working.
- Photo: replace `portrait.jpeg` under the same filename.
- Text and research: edit `index.html` using GitHub's pencil button and commit.
- Design: edit `styles.css`.

## Content notes
The supplied CV is the source for the site's academic details and SSRN links. Papers in progress are presented separately from working papers. No abstracts or publication claims have been invented. The public page uses the university email and city. The downloadable CV is included unchanged and contains the address and phone number from the supplied PDF; edit the PDF before uploading if you prefer to remove these.

No paid hosting, build tools, third-party fonts, analytics, or credentials are needed. This package has not been published to GitHub.
